# To-Do List Backend

This is the backend server for the To-Do List application, built using Node.js, Express.js, and MongoDB.

## Features
* RESTful APIs for managing tasks (CRUD operations)[cite: 1]
* Search functionality to filter tasks[cite: 3]
* Error handling and input validation[cite: 1]
